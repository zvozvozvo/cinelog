# CineLog — единая цветовая тема

Этот точечный патч убирает остатки кислотно-зелёной палитры из старых компонентов и согласует их с новой Cinema-темой: чернильно-синий фон, светлый текст и перивинкловый акцент.

## Что исправляется

- Окно «Добавить фильм»: статус, оценка, ползунок и кнопка сохранения.
- Страница «Статистика»: иконки, шкалы и акцентные действия.
- Страница «К просмотру»: иконка, кнопки, поиск и ссылки.
- Старые CSS-компоненты карточек, фокуса, пустых состояний и переходов, где ещё оставался lime-зелёный цвет.
- Добавляется последний CSS-слой совместимости для старых элементов.

Логика приложения, данные фильмов, Supabase и расчёты статистики не меняются.

## Установка

1. Распакуй ZIP поверх текущего проекта `C:\Projects\cinelog-final`, сохранив структуру папок.
2. В PowerShell в корне проекта выполни:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\apply-cinelog-color-unify.ps1
   ```

3. Скрипт внесёт только цветовые замены, импортирует CSS-слой и запустит `npm run build`.
4. Если сборка и проверки пройдут, скрипт покажет изменённые файлы. Введи `YES`, чтобы создать коммит и отправить его в `origin/main`.
5. Дождись статуса `Ready` в Vercel и обнови сайт через `Ctrl+F5`.

Если сборка не пройдёт, скрипт не будет создавать коммит или выполнять push. Изменения останутся локальными для диагностики.
