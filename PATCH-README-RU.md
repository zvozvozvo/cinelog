# CineLog Cinema Redesign — инструкция

## Что меняется

- Главный экран ставит фильм из твоего списка в центр: постер, описание, год, статус и оценка.
- Кнопка «Другой фильм» и точки выбора позволяют переключать фильмы в главном блоке.
- Полка фильмов переключается между недавними, просмотренными и отложенными.
- На телефоне постер, информация о фильме, показатели и коллекция перестраиваются в компактный интерфейс; нижняя навигация и меню «Ещё» сохранены.
- Из бокового меню и мобильного меню удалён отдельный пункт «Мои оценки». Фильтр «С оценкой» остаётся внутри архива.
- Цветовая система переведена на ночной чернильно-синий фон, бумажную типографику и мягкий проекторный оттенок. Акцент теперь поддерживает состояние и действие, а не подсвечивает всё подряд.
- Анимация появления используется сдержанно; системная настройка `prefers-reduced-motion` учитывается.

## Установка

1. Распакуй содержимое ZIP прямо в корневую папку проекта, например `C:\Projects\cinelog-final`, согласившись на замену файлов.
2. Открой PowerShell в этой папке и выполни:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\apply-cinelog-cinema-redesign.ps1
   ```

3. Скрипт запустит `npm run build`, проверит пробелы, подготовит только пять файлов патча и покажет список изменений.
4. Если всё выглядит корректно, введи `YES`. Скрипт создаст коммит и отправит изменения в `origin/main`.
5. Дождись статуса `Ready` у нового деплоя Vercel и обнови сайт жёсткой перезагрузкой `Ctrl + F5`.

Если production-сборка завершится ошибкой, коммит и push не выполнятся. Скопируй полный текст ошибки, не пытайся наугад менять команды.
