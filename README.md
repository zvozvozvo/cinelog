# CineLog

Personal cinema archive built with React + Vite + TMDB.

## Included

- Complete visual redesign across every page and component
- TMDB movie search and automatic metadata
- Watched / Watchlist states
- Personal ratings from 0 to 10
- Film detail pages with backdrop, poster, director and runtime
- Timeline
- Statistics and charts
- LocalStorage persistence
- Responsive desktop / tablet / mobile layouts

## Run

```bash
npm install
npm run dev
```

Create `.env` in the project root:

```env
VITE_TMDB_TOKEN=YOUR_TMDB_BEARER_TOKEN
```
